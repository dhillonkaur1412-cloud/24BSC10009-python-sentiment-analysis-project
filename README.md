# Sentiment Analysis System

## Description
A Python-based application that analyses multiple text reviews together and classifies them as Positive, Negative, or Neutral.

## Features
- Analyses multiple reviews in one session
- Uses positive and negative word dictionaries
- Includes basic negation handling
- Displays individual sentiment scores and an overall summary
- Provides graphical visualisation of results

## Technologies Used
- Python
- Tkinter
- NumPy
- Matplotlib
- Regular expressions

## Installation
Install the required libraries:

```bash
python -m pip install numpy matplotlib
```

## How to Run
Run the Python file:

```bash
python "sentiment analysis system.py"
```

## Method
The system uses a lexicon-based approach. It matches words against predefined sentiment dictionaries and calculates a score to classify each review.

## Limitations
The system uses simple word-matching rules and may not correctly interpret sarcasm, complex negation, or context.
